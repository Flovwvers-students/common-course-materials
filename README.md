# Общие материалы для курсов программирования

Материалы для студентов курсов C++ и Java. Начните с [установки и настройки Git и GitHub](git/setup.md). Настроить компьютер достаточно один раз; на университетском компьютере часть действий может потребоваться повторить в новой сессии.

## Материалы курсов

- [Курс C++](https://github.com/Flovwvers-students/cpp-course-materials)
- [Курс Java](https://github.com/Flovwvers-students/java-course-materials)

Порядок сдачи лабораторных и командной тренировки указан в материалах соответствующего курса. Лабораторные принимает и сливает преподаватель; правила командной тренировки на них не переносятся.
